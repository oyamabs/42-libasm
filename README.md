## Project details and constraints

Re-code some functions of the libft
- ft_strlen
- ft_strdup
- ft_strcmp
- ft_strcpy

Learn how syscalls work in assembly
- ft_write
- ft_read

The constraints are simple:
- Only use the Intel syntax
- 64 bits

## Tester

There's a simple suite of tests

## Compilation and usage

Simply use `make` to create the library. Link it to your code with `-lasm` (don't forget to tell your compiler where is the library with `-L`)

Test using the `make test` command.
